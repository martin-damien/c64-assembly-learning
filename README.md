# C64 assembly learning repository

## Stack

- [VSCode](https://code.visualstudio.com/) with [KickAss (C64)](https://marketplace.visualstudio.com/items?itemName=CaptainJiNX.kickass-c64) plugin
- [VICE](https://vice-emu.sourceforge.io/)
- [KickAssembler](https://www.theweb.dk/KickAssembler/Main.html#frontpage)

## Goal

Learn Commodore 64 assembly programming.

I currently use Kick Assembler, but the next goal will be to code directly on the C64 with [Turbo Macro Pro](https://turbo.style64.org/).

Real projects will be programmed with both, depending on the projects complexity.
